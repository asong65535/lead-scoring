## Key Features

<CardGrid>
  <Card title="Behavioral Scoring" icon="star">
    Automated lead scoring based on behavioral signals like page views, email
    clicks, and form submissions.
  </Card>
  <Card title="Real-Time API" icon="rocket">
    REST API for real-time single and batch scoring with A/B/C/D bucket
    classification.
  </Card>
  <Card title="Explainability" icon="information">
    SHAP-powered prediction logging showing top contributing factors for each
    score.
  </Card>
  <Card title="CRM Integration" icon="puzzle">
    Bidirectional HubSpot sync with webhook-triggered rescoring when lead
    properties change.
  </Card>
</CardGrid>

## Tech Stack

| Component        | Technology                      |
| ---------------- | ------------------------------- |
| Language         | Python 3.13                     |
| API Framework    | FastAPI                         |
| ML Model         | XGBoost (scikit-learn pipeline) |
| Explainability   | SHAP (TreeExplainer)            |
| Database         | PostgreSQL 15                   |
| ORM              | SQLAlchemy 2.0 (async)          |
| Migrations       | Alembic                         |
| Reverse Proxy    | Nginx                           |
| Containerization | Docker, Docker Compose          |
| Logging          | structlog                       |
